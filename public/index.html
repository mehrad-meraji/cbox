cbox

Run Claude Code in a throwaway Docker container. One-shot automation or persistent sessions that survive terminal disconnects.

$ bun install -g @_mehrad/cbox

or run without installing: bunx @_mehrad/cbox
bash
$ cbox run --mount . "add unit tests for the auth module"

✓ Reading auth.ts
✓ Writing tests/auth.test.ts (12 tests)
✓ All tests passing
Done in 23s · exit 0
$ cbox session --mount . --name refactor-auth
cbox: session a3f91b (refactor-auth) started
# Claude Code is now running interactively inside Docker
# Detach from tmux anytime — session survives terminal close
# Reattach later with: cbox attach refactor-auth
Two modes

Pick your workflow

Use one-shot mode for automation and scripting, or drop into an interactive session for longer work.

⚡

cbox run

Fire a prompt, stream the output, exit with the container's exit code. Pipe it, script it, automate it.

$ cbox run "refactor auth to JWT"
$ cbox run -j "find TODOs" | jq
$ cbox run -f task.md --mount ./src
🖥

cbox session

Interactive Claude Code session backed by tmux on the host. Disconnect and reconnect anytime.

$ cbox session --name my-task
$ cbox list
$ cbox attach my-task

Everything runs through the cbox binary.

Features

What's inside

cbox is a thin coordinator — Docker, tmux, and Claude Code do the heavy lifting.

🐳

Docker isolation

Every run is a throwaway container. Nothing leaks to your host filesystem unless you mount it.

🔄

tmux persistence

Sessions survive terminal disconnects via host-side tmux. Reattach by name or ID anytime.

🌐

MCP servers

Host skills and MCP config mounted read-only. localhost URLs rewritten to host.docker.internal automatically.

🖥

agent-browser

Chrome baked into the image. Headless browser automation available inside every container.

📋

JSON output

Use -j to get structured output — always valid JSON, even on failure. Safe to pipe into jq.

🚀

Raycast integration

Script Commands for listing, attaching, killing sessions, and running prompts — without a terminal.

🔑

Secure by design

API key passed by reference, never embedded. ~/.claude mounted read-only. MCP patches go to tmpdir.

📦

Zero config

Image builds automatically on first run. Rebuilds only when CLI version or MCP packages change.

Get started

Install cbox

Pick your preferred setup method.

Prerequisites
✓ Docker installed and running
✓ Claude Code installed and logged in (claude login)
✓ tmux — required for cbox session and cbox attach
# global install
$ bun install -g @_mehrad/cbox
# or run without installing
$ bunx @_mehrad/cbox "your prompt"
# pull the prebuilt image
$ docker pull registry.gitlab.com/mehrad.meraji/cbox:latest
# run a prompt directly
$ docker run --rm -it \
-e ANTHROPIC_API_KEY \
-v ~/.claude:/root/.claude:ro \
--add-host=host.docker.internal:host-gateway \
registry.gitlab.com/mehrad.meraji/cbox:latest \
claude --dangerously-skip-permissions "your prompt"
# or use cbox run/session to manage it automatically

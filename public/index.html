Two modes

Pick your workflow

One-shot for automation and scripting. Session for interactive, persistent work that survives disconnects.

run

One-shot

Fire a prompt, stream output, exit with the container's exit code. Pipe it, script it, automate it.

$ cbox "refactor auth to JWT"
$ cbox run -j "find TODOs" | jq
$ cbox run -f task.md -m ./src
session

Persistent session

Interactive Claude Code backed by tmux on the host. Disconnect and reconnect anytime — session survives.

$ cbox session --name refactor
$ cbox list
$ cbox attach refactor
Mounts

Bring your code in

Pass -m once or multiple times. Single mounts land at /workspace; multiple mounts are auto-named by directory basename.

Single mount → /workspace
# read-write (default)
$ cbox run -m .
 
# read-only
$ cbox run -m ./src:ro
 
# absolute path
$ cbox run -m /abs/path
Multiple mounts → /workspace/<name>
# src → /workspace/src
# tests → /workspace/tests
$ cbox run -m ./src -m ./tests
 
# mixed modes
$ cbox run -m ./src -m ./data:ro
 
# works in session mode too
$ cbox session -m ./src -m ./data
Features

What's inside

cbox is a thin coordinator. Docker, tmux, and Claude Code do the heavy lifting.

Docker isolation

Every run is a throwaway container. Nothing touches your host unless you explicitly mount it.

tmux persistence

Sessions survive terminal disconnects via host-side tmux. Reattach by name or ID anytime.

MCP + skills

Host ~/.claude mounted read-only. localhost URLs rewritten to host.docker.internal automatically.

agent-browser

Chrome baked into the image. Headless browser automation available in every container, no setup.

JSON output

Use -j for structured output. Always valid JSON, even on failure. Safe to pipe into jq.

Raycast

Script Commands for listing, attaching, and running prompts without opening a terminal window.

Secure by design

API key by reference only. ~/.claude read-only. MCP patches written to tmpdir — host config never touched.

Zero config

Image builds on first run and caches. Rebuilds automatically only when your CLI version or MCP packages change.

--no-browserSkip agent-browser
